🔧 System Design Principles Applied (Hard-to-Vary Explanations):
• Dry-run mode is intentional: GitHub Pages cannot run server-side code. Prediction: App generates correct permutations without API calls. Test: Compare output against manual pattern expansion.
• Prioritized patterns first: 8 high-probability patterns tested before 24 fallbacks. Prediction: 80%+ of valid corporate emails match a priority pattern. Test: Run against 100 known-valid emails.
• Stateless frontend: Zero data storage; all processing in-browser memory. Prediction: Reload page mid-generation → state resets. Test: Refresh during generation.
• Copy-to-clipboard workflow: Generates list → you copy to paid verifier. Prediction: Reduces wasted credits on impossible patterns. Test: Measure credit savings vs. brute-force approach.
• Local proxy fallback: If running on localhost, app attempts to use local proxy. Prediction: Direct API calls succeed when proxy is running. Test: Start proxy.js locally → app switches to "proxy mode".
